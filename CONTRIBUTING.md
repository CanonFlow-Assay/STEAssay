# Contributing

Keep changes small, deterministic, and evidence-carrying. Do not add protected ASD-STE100 text, dictionary entries, or derived default vocabulary. New blocking checks need a deterministic syntax or configured-data basis, a documented falsifier, good/bad fixtures, and tests. Grammar heuristics are advisory.

Run `npm run verify` before proposing a change. This repository uses Apache-2.0; contributions are accepted under that licence.
