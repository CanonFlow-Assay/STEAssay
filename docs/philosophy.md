# Philosophy

STEAssay observes evidence, rather than asserting universal qualities of prose. Its authority is bounded by the policy, supplied data, reachable Markdown files, parser behaviour, and command receipts. Therefore:

> authority ≤ evidence ≤ observed scope

An empty finding list is not a verdict. `Pass` requires complete observed scope and successful configured verification evidence. Missing or invalid configuration, unreadable glossary/vocabulary, parse failure, omitted scope, or unavailable/failed required commands cannot become `Pass`.

The tool purposely separates deterministic checks from language judgement. A configured term match is mechanically falsifiable. Whether a passive construction is appropriate requires context, so its pattern is advisory.
